
## Getting Started

First, run the development server:

```bash
cd backend

python -m uvicorn main:app --reload
```

Open [http://127.0.0.1:8000/](http://127.0.0.1:8000/) with your browser to see the result.

Open [http://localhost:8000/docs](http://localhost:8000/docs) with your browser to see the docs result.

You can start editing the page by modifying `main.py`.
